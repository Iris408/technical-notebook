# ミニマル技術ノート

HTML、CSS、JavaScript で作成した single-file の技術ノートです。

**英語版：** [English](#english-version)

## 機能

- ミニマルでレスポンシブなレイアウト
- ホームページに選んだ技術ノートを表示
- ノートを展開して詳細を表示
- すべてのノートを新しい順・古い順で閲覧
- About セクションと GitHub・LinkedIn へのリンク
- 日本語 / 英語の言語切り替え
- ライト / ダークモード
- `index.html` のみで構成

About と全ノートは、別ファイルではなく同じページ内で表示されます。

## 目的

開発の進捗、デバッグ記録、プロジェクトで学んだこと、技術日本語の練習を記録する個人技術ノートです。各ノートは、問題・原因・修正・学びを中心にまとめています。

## 使用技術

- HTML
- CSS
- JavaScript

## ローカルで表示する

`index.html` をブラウザーで開くか、プロジェクトのディレクトリで簡易サーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。

# Minimal Technical Notebook

A single-file technical notebook built with HTML, CSS, and JavaScript.

**日本語版：** [日本語の説明へ](#japanese)

## Features

- Minimal, responsive layout
- Selected technical notes on the homepage
- Expandable notes with details
- Full notes archive with newer-first and older-first ordering
- About section with GitHub and LinkedIn links
- Japanese / English language toggle
- Light / dark mode
- Built entirely in `index.html`

The About and full Notes views are displayed within the same page; they are not separate HTML files.

## Purpose

A personal technical notebook for recording development progress, debugging notes, project lessons, and technical Japanese practice. Each note follows a problem, cause, fix, and lesson structure.

## Tech stack

- HTML
- CSS
- JavaScript

## View locally

Open `index.html` in a browser, or start a simple server from the project directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
